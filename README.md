## 🧬 Who am I?

**Syrins** — full-stack developer, infra builder and the person behind the **Syrins ecosystem**  
(Dev tools, CORS proxy, monitoring, security PoCs, desktop apps, AI tools, games… hepsi aynı çatı altında.)

- 🧠 I enjoy **complex systems**: CORS proxies, API gateways, monitoring dashboards, security tooling.
- 🧱 I like **infrastructure that doesn’t die**: reverse proxies, rate limiting, SSRF protections, failover setups.
- 🧪 I build a lot of **“real” tools**: not just demos, but things that can sit in real pipelines.
- 🎮 Side quests: C++ & C# games, AI experiments, small desktop utilities.
- 🌍 Brand: **Syrins Tech A.Ş · Turkey** — everything I do tries to live under that brand.
